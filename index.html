Supabase 免费方案可保存这份小型家庭记录。先建项目并运行压缩包内的 SQL，然后在这里填项目 URL 和 Publishable / anon key。

网页只使用 Publishable / anon 客户端 key；绝不要填 service_role 或 Secret key。家庭照片保存在私有桶中，只有登录账号可读取。

家庭账号

先创建一次家长账号；之后手机、电脑都用同一组邮箱和密码登录。

若创建后要求邮箱验证，请按邮件提示完成；也可以在 Supabase Auth 设置中调整测试项目的邮箱确认方式。
